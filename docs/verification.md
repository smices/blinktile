# 验收记录

截至 2026-09-23。这里只列当前版本的结果；软件模拟、固件编译、烧录、串口读回和肉眼观察是不同证据，不互相替代。逐项实物检查见[真机验收表](hardware.md)。

## 已完成

| 范围 | 结果 |
| --- | --- |
| `bash tools/test.sh` | 2026-09-23 通过：46 个图标、95 个字形、58 个 GIF 解码；网页控制器和 WebSocket 模拟器；协议与配网页边界；250 组原生固件 C++ 与网页渲染对照、5 个非法文本拒绝；竖线雨密度、绿色明暗、桌宠节奏和临时命令恢复。 |
| `codex-status/.venv/bin/python codex-status/test_codex_status.py` | 2026-09-23 通过 6 项：hook 脱敏、会话／子代理状态、其他应用占用保护、串口分帧，以及模拟 BLE GATT 分包、通知拼包和设备选择。 |
| `bash tools/build.sh` | 当前 ESP32-C3 固件使用 `huge_app` 分区编译通过：程序 1,368,037 字节（43%），静态 RAM 51,712 字节（15%）。 |
| 烧录与串口 | 当前固件已烧录至连接的 ESP32-C3，写入哈希验证通过。重启后 `get` 读回桌宠模式、默认亮度 64/255；再发送亮度指令，读回 8/255（约 3%，重启后恢复默认）。此前串口实测临时 `loading` 到期后返回桌宠。 |
| Codex 桥接 | USB 串口桥接曾重新连接并在 `127.0.0.1:8766` 接收合成 `UserPromptSubmit`、`Stop` hook（HTTP 204）；这验证事件入口，不证明当前 Codex 客户端已信任并实际触发 hook。 |

早期实物曾确认红绿蓝、四方向图标和逐行线性映射可辨；这不是新版竖线雨的肉眼验收。网页预览素材已重新生成并检查，但 GIF 与屏幕预览也不能替代灯板观感。
