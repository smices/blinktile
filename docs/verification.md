## 2026-09-24 BLE 物理授权（待实物验收）

新代码允许设备运行后按住 BOOT 键至少 1 秒，对当前 BLE 会话执行无密钥 `auth`；一次长按只授权一次，松开才重新启用。不会通过 BLE 返回长期控制密钥，WebSocket 仍要求密钥。网页 BLE 连接与 codex-status 桥接均支持有限时间重试。原生固件传输测试覆盖按键持续时间、释放后拒绝、仅 BLE 可无密钥授权及一次长按不重复授权；桥接模拟测试覆盖重试、超时和原有密钥路径。`bash tools/test.sh` 与 `bash tools/build.sh` 已通过。

用户本轮暂时不方便按实体 BOOT 键，因此**尚未烧录此版固件，也尚未将正在运行的 USB 桥接切到 BLE**。BLE 扫描、按键认证和状态显示不能标记为真机通过；先前 8/255 的设备运行亮度不因代码构建而改变。
